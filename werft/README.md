# The Werft

*[Deutsch weiter unten ↓](#die-werft-deutsch)*

The Werft is an AI-driven software build pipeline: you describe what you
want built in plain prose — an "order" — and a team of local language
models, each acting in a fixed role (Coordinator, Planner, Summarizer,
Coder, Debugger, Analyst, Strategist, Judge), turns that into runnable
Python code, verifies it against your specification, and delivers it. No
human writes the code; the pipeline tracks every order through a
persistent database, with a mandatory, executable acceptance criterion
deciding pass or fail, and several self-healing mechanisms that resolve
known blockages without a human in the loop.

## Die Werft (Deutsch)

Die Werft ist eine KI-gestützte Software-Baupipeline: Man beschreibt in
Prosa, was gebaut werden soll — eine „Bestellung" — und ein Team lokaler
Sprachmodelle in festen Rollen (Coordinator, Planer, Summarizer, Coder,
Debugger, Analyst, Stratege, Judge) erzeugt daraus lauffähigen Python-Code,
prüft ihn gegen die Spezifikation und liefert ihn aus. Kein Mensch schreibt
dabei Code; die Pipeline verfolgt jede Bestellung über eine persistente
Datenbank, ein verpflichtendes, ausführbares Abnahmekriterium entscheidet
über Erfolg oder Misserfolg, und mehrere Selbstheilungs-Mechanismen lösen
bekannte Blockaden ohne menschliches Eingreifen auf.
